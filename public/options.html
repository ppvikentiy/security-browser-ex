Исключённые домены

По одному домену на строку. Расширение не активируется на этих сайтах.

Расширение включено
Глобально отключает все модули (то же, что переключатель в попапе)

Список доменов

• Обычное имя хоста (например example.com) отключает расширение на самом домене и всех поддоменах
• Строку *.example.com можно использовать — при сохранении она эквивалентна example.com
• Можно вставить полный URL — сохранится только имя хоста
• Сложные шаблоны с * допускаются; одна строка * игнорируется
• Во всех остальных местах расширение включено по умолчанию

Активная интернет защита

Красное предупреждение только в главном окне вкладки. Важно: если тот же домен указан в разделе «Исключённые домены», расширение там полностью выключено — предупреждение появится только после удаления этого домена из исключений (список «подозрительных доменов» от этого не включит модуль сам по себе). Для SPA (VK и др.) баннер удерживается на странице и при необходимости восстанавливается. Локальные и приватные адреса (localhost, 192.168.x.x) для проверки HTTP не считаются. Ложные срабатывания — белый список или отключение отдельных правил.

Включить активную защиту
Применяется только вне «Исключённые домены» и при глобально включённом расширении

Условия предупреждения

Страница по HTTP
Не срабатывает на localhost и LAN (см. Network Security)

Встроенные шаблоны (*.tk и др.) + ваши строки ниже
«Двойной» домен (накладочный TLD)
Шаблоны вроде example.com.ru, example.net.xyz (настраиваемые суффиксы из кода расширения)
Очень длинное / шумное имя хоста

Доп. подозрительные домены и шаблоны (одна строка = один паттерн)

Белый список (никогда не предупреждать, если совпало)

Защита устройства

Жёсткая защита от извлечения/загрузки локальных данных и от попыток понять, есть ли у вас устройство/гео. Этот модуль может ломать сайты — включайте, только если готовы к поломкам.

Включить защиту устройства
Применяется только вне доменов из «Исключённые домены»
Важно
В режиме «жёстко» сайт может получать undefined вместо API и/или ошибки SecurityError. Это сделано намеренно, чтобы страница не успевала увидеть реальные данные.

Network Security

Защита от веб‑страниц, которые пытаются подключиться к вашему localhost, локальной сети (RFC1918) или уменьшают утечки через WebRTC. Внешний скан вашего публичного IP браузерным расширением остановить нельзя — см. блок ниже (роутер / файрвол).

Включить Network Security
Применяется вне доменов из «Исключённые домены»
Внешний онлайн‑скан портов
Скан «с интернета» идёт к вашему NAT/роутеру; расширение его не режет. Отключите Перенаправление портов (port forwarding) и при возможности UPnP; проверьте Файрвол Windows (разрешённые входящие правила); не публикуйте лишние сервисы наружу.

Блокировка из страницы (LAN / loopback)

Блокировать частные / link‑local сети
10.*, 192.168.*, 172.16–31.*, 169.254.*, ULA IPv6, fe80::
Блокировать localhost / loopback
localhost, 127.*, ::1
Блокировать встроенные зонды
img / iframe / object / embed — не применяется на самих LAN‑страницах

Privacy pack (Declarative Net Request)

Отдельно от ADS Block: только сетевая блокировка малого списка сторонних трекер‑доменов (без косметики и попапов). Работает вне доменов из раздела «Исключённые домены». Типы ресурсов по умолчанию узкие (script / XHR / ping) — см. переключатель ниже.

Включить Privacy pack
DNR блок по списку доменов ниже и встроенному набору
Расширенный набор типов запросов
Как блок телеметрии в ADS Block (iframes, image, websocket…). Выше шанс поломать сайты

Изоляция (chrome.privacy)

Жёсткие настройки браузера: отключение отправки заголовка Referer, ping по ссылкам (a ping) и сетевого prefetch (Network Prediction). Если что‑то сломало оплату или вход — добавьте сайт в «Исключённые домены» для модулей DNR здесь это не восстанавливает Referer: выключите соответствующий пункт или снимите ограничение в Chrome.

Не отправлять Referer
chrome.privacy.websites.referrersEnabled → false — высокий риск SSO / оплат / CDN
Отключить аудит ссылок (ping)
hyperlinkAuditingEnabled → false
Отключить предсказание сети (prefetch/DNS prefetch)
networkPredictionEnabled → false. Меньше префетча, может изменить ощущаемую скорость

ADS Block

Ранее модуль «DS Block». Блокировка всплывающих окон, рекламных баннеров и части телеметрии. Может ломать логин/виджеты/аналитику — включайте точечно и используйте «Исключённые домены» при проблемах. Встроенные CSS‑правила для типичной рекламы (AdSense, GPT, частые сети) расширены, но не заменяют полноценный блокировщик — под свою вёрстку добавляйте селекторы ниже.

Включить ADS Block
Применяется только вне доменов из «Исключённые домены»
Важно
«Телеметрия» здесь означает домены аналитики/пикселей/трекеров. Если сломался вход (OAuth), чат, видео или кнопки — сначала выключите телеметрию, затем добавьте сайт в «Исключённые домены».

Что блокировать

Попапы (window.open)
Вызовы без пользовательского жеста и программные клики по ссылкам с target=_blank
Баннеры (косметика)
Скрытие элементов по CSS селекторам
Телеметрия (сеть + sendBeacon)
Блок доменов аналитики через DNR; может ломать сайты

Пользовательские списки

Доп. домены для блокировки (по одному на строку)
Эти домены добавляются к встроенному небольшому списку и используются для блокировки запросов к телеметрии/рекламе.
CSS селекторы для скрытия (по одному на строку)
Селекторы применяются к странице через инъекцию CSS и работают быстрее, чем скриптовые «поиски» элементов. К встроенному списку (см. описание панели выше) добавляются только ваши строки; агрессивные правила вводите вручную.
