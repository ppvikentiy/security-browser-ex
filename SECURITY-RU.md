# SECURITY.md

## Политика безопасности и обработки данных

### 1. Общие положения

«Browser Security» — расширение для браузеров на базе Chromium (Manifest V3),
работающее как локальный слой защиты между веб-страницей и браузером.

Программное обеспечение не имеет серверной части, облачной инфраструктуры и
модулей телеметрии. Все функции выполняются исключительно локально на устройстве
Пользователя в автономном (офлайн) режиме.

### 2. Обработка персональных данных и статистики

Разработчик и/или компания не осуществляют сбор, хранение, обработку, передачу
третьим лицам или иное использование персональных данных и/или статистики
использования Программного обеспечения.

### 3. Передача данных

Никакие данные не покидают устройство Пользователя и не передаются Разработчику
и/или компании, а равно третьим лицам, за исключением данных, которые Программное
обеспечение в конкретный момент времени изменяет (подменяет) в технических целях
и которые объективно необходимы для корректной работы посещаемых Пользователем
веб-сайтов.

### 4. Сведения о посещаемых ресурсах

Разработчик и/или компания не имеют технической возможности и не осуществляют
получение, фиксацию или анализ сведений о веб-сайтах, посещаемых Пользователем.

### 5. Сведения об устройствах

Разработчик и/или компания не получают и не обрабатывают информацию об
устройствах, на которых установлено Программное обеспечение, включая, помимо
прочего, их количество, идентификаторы, технические характеристики и иные
параметры.

### 6. Локальное хранение данных

Настройки Программного обеспечения и обезличенные технические счётчики хранятся
только на устройстве Пользователя средствами браузера (chrome.storage) и не
передаются за его пределы. Конфиденциальные сведения — история посещений,
cookies, пароли, данные форм, содержимое страниц, данные камеры и микрофона —
Программным обеспечением не читаются и не сохраняются.

### 7. Разрешения

Используемые разрешения (storage, tabs, windows, scripting,
declarativeNetRequest, privacy, доступ к сайтам) необходимы исключительно
для выполнения заявленных функций Программного обеспечения и не используются
для сбора данных.

### 8. Сообщение об уязвимостях

При обнаружении проблемы безопасности откройте issue в репозитории:
https://github.com/ppvikentiy/security-browser-ex

Не публикуйте эксплойты публично до выхода исправления. В описании укажите
версию расширения (поле version в manifest.json) и шаги воспроизведения.
